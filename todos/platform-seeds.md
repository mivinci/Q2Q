# 平台种子页面与本地解析

## 已确认设计

- `/seeds` 是当前项目种子（发布版本）列表，提供「解析种子」弹窗。
- `/seeds/[id]` 使用发布版本 ID，展示内容身份、来源文件与发布状态，后续承载分发统计；不伪造尚未接入的上传量、下载量或节点数。
- 文件详情的发布版本 ID 链接到种子详情。
- 解析复用 core Seed::parse/validate，通过 q2q-wasm 薄接口返回可读字段；浏览器本地执行，不上传文件、不请求种子内 URL、不自动创建记录或授权。
- 解析展示文件元信息、块信息、info_hash、Merkle 根及证明状态。来源只展示站点，隐藏路径、query、用户信息与 fragment，避免下载授权泄漏。
- 与当前页面已加载且有权限查看的发布版本按 info_hash 在本地匹配，提供详情链接；不将本地导入的来源 URL 当作可信平台链接。
- 列表第一版显示当前项目最近 100 条发布版本，明确说明范围；分页与真实统计后续实现。
