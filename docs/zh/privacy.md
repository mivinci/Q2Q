# Q2Q 平台隐私政策

生效日期：2026 年 10 月 18 日

本政策说明你使用 [platform.q2q.app](https://platform.q2q.app) 上的账户、项目、存储、种子处理和发布功能时，Q2Q 平台如何处理相关信息。本政策不适用于由其他运营方独立提供的 Track、Punch、存储或 CDN 服务。

## 我们处理的信息

- **登录信息。** 使用 Google 或 GitHub 登录时，我们会收到相应服务提供方提供的基本账户资料，例如提供方账户 ID、姓名、电子邮箱和头像，用于创建和维护 Q2Q 账户。我们不会申请访问 Google Drive、Gmail 等无关服务。登录所需的 OAuth 凭据会以加密形式保存。
- **账户与安全信息。** 我们保存账户和会话记录。会话可能包含登录请求提供的 IP 地址和浏览器 User-Agent，用于验证会话、保护服务和排查运行问题。
- **项目信息。** 我们保存项目名称、成员与邀请状态、所选存储和网络配置，以及运行项目功能所需的相关记录。邀请链接在数据库中以令牌哈希形式保存。
- **文件与发布信息。** 上传文件时，我们会处理文件内容、文件名、大小、上传状态，以及生成的种子和内容证明产物。我们还会保存内容标识、配置的 Track 地址和下载授权状态等发布信息。
- **偏好与 Cookie。** 必要 Cookie 用于维持登录会话，并记住界面语言和当前项目。外观偏好保存在你的浏览器中。平台目前不使用广告 Cookie 或第三方分析工具。

使用平台的种子解析器检查 `.q2q` 文件时，解析过程在浏览器本地进行，不会上传该文件，也不会访问文件中包含的地址。

## 信息用途

我们使用这些信息来验证身份；运行账户、项目和邀请功能；保存上传文件；生成种子与证明；向所选分发网络发布内容；执行项目访问和存储额度校验；防止滥用；以及维护服务安全和稳定运行。

## 存储与服务提供方

Q2Q 平台运行在 Cloudflare Workers 上，并使用 Cloudflare D1、R2 和 Queues 保存账户与项目信息、上传内容及处理任务。你选择 Google 或 GitHub 登录时，相应提供方会处理登录信息。这些服务提供方依照各自的条款和隐私政策处理信息：

- [Google 隐私权政策](https://policies.google.com/privacy)
- [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
- [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)

我们不会出售个人信息，也不会将其用于定向广告。法律要求时，或为保护用户、服务及他人所合理必需时，我们可能会披露相关信息。

## 分发与主动分享的信息

发布内容或分享种子、下载授权时，种子中可能包含内容标识，以及该发布版本配置的 Track 或下载来源地址。获得有效种子或授权的人可能在授权有效期间下载该版本。你可以撤回发布或撤销授权；已经签发的链接最多可能需要五分钟才会失效。

下载方会连接到发布版本指定的 Track、Punch、存储、CDN 和 peer 服务。这些服务及其运营方可能会收到 IP 地址等连接信息。Q2Q 不控制由其他运营方独立提供的服务，使用前请查看其隐私政策。

## 信息保留与控制

会话有效期为七天，除非期间刷新；退出登录会结束当前会话。上传的文件及其生成产物会保留在项目中，直到有权限的项目成员将其删除。删除和发布产物清理通过异步任务处理，因此不会立即完成。为运行和保护服务所需期间，我们会保留账户、项目和安全记录；法律另有要求的除外。

平台目前不支持自助删除账户。如需查询、更正或申请删除账户信息，请联系 [mivinci@foxmail.com](mailto:mivinci@foxmail.com)。我们可能需要先验证你的身份，并考虑项目所有权、其他成员的访问、服务安全和适用法律要求后处理请求。

## 信息安全

我们采用 OAuth 凭据加密、会话控制和项目成员权限校验等措施保护信息。任何互联网服务都无法保证绝对安全；请妥善保管登录账户以及你分享的种子和下载链接。

## 政策更新与联系

平台功能变化时，我们可能更新本政策。最新版本会发布在此页面，并注明生效日期。如有隐私问题，请联系 [mivinci@foxmail.com](mailto:mivinci@foxmail.com)。
